Integer Overflow Lab

Integers in C live in a fixed number of bits. When a value needs more bits than it has, the extra ones are thrown away and the number wraps around. Set a width and a signedness below, then poke at the bits.

1 · One value, two meanings

two's complement

The same bit pattern is read as a different number depending on whether the type is signed or unsigned. Click any bit to flip it, drag the slider, or type a value. Watch the signed and unsigned readouts disagree once the top bit turns on.

3 · Why it bites: allocation size overflow

real-world

A very common bug: code computes count × element_size to decide how many bytes to allocate. If that product overflows, the program asks for a tiny buffer, then happily writes count elements into it — straight past the end. This panel only illustrates the arithmetic; it allocates nothing.
